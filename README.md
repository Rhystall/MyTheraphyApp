# 💊 MyTherapy

**MyTherapy** adalah aplikasi mobile yang dirancang untuk membantu pengguna dalam mengatur dan mengingat jadwal minum obat. Aplikasi ini memungkinkan pengguna menambahkan, mengedit, dan menghapus pengingat obat secara mudah, serta memberikan notifikasi tepat waktu sebagai pengingat konsumsi obat.

---

## ✨ Fitur Utama

- ✅ Tambah Obat  
- 🗑️ Hapus Obat  
- ✏️ Edit Obat  
- 🔔 Notifikasi Pengingat  
- 🔍 Cari Obat di Daftar Obat  
- 👤 Halaman Profil Pengguna
